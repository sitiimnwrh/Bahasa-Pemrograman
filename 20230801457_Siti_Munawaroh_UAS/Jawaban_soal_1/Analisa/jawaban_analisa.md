# Pengertian Function 
#### Function atau fungsi adalah blok kode yang dapat digunakan kembali untuk menjalankan tugas tertentu. Fungsi dapat menerima input dalam bentuk parameter dan mengembalikan output. Fungsi membantu membuat kode lebih modular dan mudah dibaca.

# Pengertian Recursive
#### Recursive atau rekursi adalah teknik dalam pemrograman di mana sebuah fungsi memanggil dirinya sendiri. Rekursi digunakan untuk memecahkan masalah yang dapat dipecah menjadi sub-masalah yang lebih kecil dan mirip dengan masalah asli.
