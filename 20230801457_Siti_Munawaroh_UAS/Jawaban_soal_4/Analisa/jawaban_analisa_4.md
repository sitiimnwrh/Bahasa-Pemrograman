# Pengertian Database
#### Database adalah sistem yang digunakan untuk menyimpan, mengelola, dan mengorganisir data secara terstruktur. Database memungkinkan pengguna untuk menyimpan informasi secara efisien dan mengakses data tersebut dengan cara yang cepat dan mudah. Data dalam database biasanya disimpan dalam format yang memudahkan pencarian, pengeditan, dan pemeliharaan informasi.

# Komponen Utama Database
1. Tabel: Struktur dasar dalam database yang menyimpan data dalam bentuk baris dan kolom. Setiap baris mewakili satu record, dan setiap kolom mewakili atribut dari record tersebut.

2. Record (Baris): Satu unit data dalam tabel, sering disebut sebagai tuple atau row. Setiap record menyimpan data untuk satu entitas.

3. Field (Kolom): Setiap kolom dalam tabel yang menyimpan jenis data tertentu. Misalnya, dalam tabel pengguna, kolom mungkin termasuk ID, Nama, Email, dan Tanggal_Lahir.

4. Schema: Struktur atau desain database yang mencakup tabel, kolom, hubungan antara tabel, dan aturan yang berlaku untuk data. Schema mendefinisikan bagaimana data diorganisir dan dikaitkan satu sama lain.

5. Query: Permintaan untuk mengakses atau memanipulasi data dalam database. Query biasanya ditulis dalam bahasa SQL (Structured Query Language).

6. Index: Struktur data yang meningkatkan kecepatan pencarian dan pengambilan data dari tabel. Index memungkinkan database untuk menemukan data dengan lebih efisien.

# Jenis-jenis Database
1. Database Relasional (RDBMS):

* Menggunakan tabel untuk menyimpan data dan mendefinisikan hubungan antar tabel.
Contoh: MySQL, PostgreSQL, Oracle, SQLite.
Database Non-Relasional (NoSQL):

* Menyimpan data dalam format yang tidak berbasis tabel. Biasanya digunakan untuk data yang tidak terstruktur atau semi-struktur.
Contoh: MongoDB (dokumen), Cassandra (kolom), Redis (key-value), Neo4j (graf).
2. Database Hierarkis:

* Mengorganisir data dalam struktur pohon dengan hubungan parent-child.
Contoh: IBM Information Management System (IMS).
Database Jaringan:

* Memungkinkan banyak hubungan antar record dengan struktur grafik.
Contoh: Integrated Data Store (IDS).
# Kegunaan Database
1. Penyimpanan Data: Menyimpan data dalam format yang terstruktur untuk akses dan pengelolaan yang efisien.

2. Pencarian Data: Memungkinkan pencarian dan pengambilan data secara cepat menggunakan query.

3. Pengelolaan Data: Mengelola data dengan cara menambah, mengedit, atau menghapus record.

4. Keamanan Data: Mengontrol akses ke data dengan hak akses dan otorisasi pengguna.

5. Integritas Data: Menjaga konsistensi dan akurasi data melalui aturan dan batasan.

6. Analisis Data: Menyediakan kemampuan untuk menganalisis data dan menghasilkan laporan serta informasi yang berguna.
